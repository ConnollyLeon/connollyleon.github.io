# 军事动态：AEVEX最高6.5亿美元收购BlackSea Technologies、DISA确定8月24日发布JWCC后续云招标、太空军增购Impulse Space轨道机动飞行器

本周美国国防采购领域呈现"无人系统整合"与"云能力扩张"两条主线。8月13日，防务技术公司AEVEX宣布以最高6.5亿美元收购海军无人艇技术公司BlackSea Technologies，意图在无人水面与水下作战领域扩大布局；8月11日，国防信息系统局（DISA）在8月采购决策公告中将"JWCC统一云市场"后续合同的最终招标文件发布日期定为8月24日，并计划将采购范围扩至大型云商之外；8月12日，太空军向Impulse Space追加2800万美元合同，采购两艘额外的机动航天器用于快速响应太空任务。无人化、云化与轨道机动正在同步加速。

## 主要新闻

### AEVEX以最高6.5亿美元收购BlackSea Technologies，押注无人水面/水下作战

Breaking Defense于8月13日报道，防务技术公司AEVEX宣布收购海军技术公司BlackSea Technologies，交易对价最高6.5亿美元，预计9月完成交割。双方表示，此次收购旨在强化AEVEX在无人水面与水下作战领域的布局，并扩大对海军、美国特种作战司令部（USSOCOM）及其他盟国伙伴的"客户接入"能力，实现"空中、水面与水下平台的互补技术整合"。BlackSea Technologies是Global Autonomous Reconnaissance Craft（GARC）的研制方——这是一款16英尺级小型无人自主艇，美国海军正在科罗纳多海军基地（Naval Base Coronado）对其进行试验，2024年成立的第3无人水面艇中队（Unmanned Surface Vessel Squadron 3）负责运营。AEVEX总部位于加州Solana Beach，开发包括名为Mako的无人水面艇在内的一系列自主系统，Mako面向情报、监视与侦察（ISR）以及动能作战任务。交易结构为：2.5亿美元现金、约3.5亿美元AEVEX Class A普通股，外加最高5000万美元的业绩对价（earnout）。AEVEX创始人与执行董事长Brian Raduenz表示："BlackSea带来卓越且战略契合的海上能力，同样重要的是，它带来了以任务为中心的文化。"BlackSea CEO Bob Pudney则称，AEVEX提供了"规模化、制造深度与自主生态"来加速其一切成果，使命不变、交付能力增长。

**Source:** [AEVEX to acquire BlackSea Technologies for up to $650M](https://breakingdefense.com/2026/08/aevex-to-acquire-blacksea-technologies-for-up-to-650m/)

### DISA确定8月24日发布JWCC后续云招标，采购范围扩至大型云商之外

Washington Technology于8月11日报道，DISA最新采购日程将美国军方主云合同下一版本的最终招标文件（final solicitation）发布日期定为8月24日。该合同即"联合战士云能力"（Joint Warfighter Cloud Capability，JWCC），是国防部从主要超大规模云商——AWS、Google、Microsoft Azure与Oracle——采购云服务的机制。新版合同将更名为"JWCC统一云市场"（JWCC Unified Cloud Marketplace），扩大国防部可通过该机制采购的范围。其分层设计为：Tier 1面向超大规模云商；Tier 2覆盖"一切即服务"（Everything-as-a-Service），包括软件、平台与非超大规模基础设施；Tier 3则专门为"商业创新者与小企业"保留，由新兴公司与小企业组成。DISA尚未公布"JWCC统一云市场"的预计合同总额；现有JWCC合同设有90亿美元的上限。Deltek数据显示，截至目前AWS获得5.265亿美元任务订单义务（task order obligations），微软以2.21亿美元居次，Oracle以7690万美元位列第三，Google为3590万美元。此次扩展的意图明确：在保留四家超大规模云商主干的同时，把国防部云生态向中层与新兴厂商开放，以引入更多创新与竞争。

**Source:** [DISA sets release date for follow-on cloud solicitation](https://www.washingtontechnology.com/contracts/2026/08/disa-sets-release-date-follow-cloud-solicitation/415341/)

### 太空军增购Impulse Space轨道机动飞行器，扩大快速响应太空能力

SpaceNews于8月12日报道，美国太空军向Impulse Space现有合同追加2800万美元，采购两艘额外的机动航天器，用于战术响应太空（tactically responsive space）任务，扩大这家初创公司在"为军事操作人员提供更快在轨响应选项"方面的角色。合同修订将资助Victus Salo 2与Victus Salo 3任务，二者将使用Impulse的Mira航天器在低地球轨道承载政府提供的有效载荷。此次追加使合同总值增至约6280万美元；原合同为太空系统司令部（Space Systems Command）的Space Safari办公室联合国防创新单元（DIU）于2024年授予的3480万美元小企业创新研究（SBIR）第三阶段协议，覆盖Victus Surgo与Victus Salo 1任务。Victus Salo隶属于太空军更广泛的战术响应太空（TacRS）计划，旨在缩短部署与运行航天器的时间；与早期聚焦"快速发射"不同，Victus Salo测试的是"已在轨、可快速机动"的航天器。首个Victus Salo任务将让一艘Mira在低地球轨道运行，搭载麻省理工学院林肯实验室提供的政府载荷；Victus Salo 1预计2027年发射。Victus Surgo则更具雄心：由Impulse的Helios高能末级把另一艘Mira从低地球轨道送往地球同步转移轨道（GTO），随后Mira独立机动。Mira是高推力航天器，可承载并部署最高300公斤有效载荷，使用8台以氧化亚氮和乙烷为燃料的推进器，公司已三次飞行Mira。Impulse Space于2021年由前SpaceX推进系统高管Tom Mueller创立，上个月刚被纳入国家安全太空发射（NSSL）第三阶段第一通道（Lane 1）合同，可作为上面级供应商参与竞争。

**Source:** [Space Force orders two more Impulse Space vehicles for maneuvering demonstrations](https://spacenews.com/space-force-orders-two-more-impulse-space-vehicles-for-maneuvering-demonstrations/)

## 分析

AEVEX收购BlackSea是"无人化平台横向整合"的代表案例。交易的核心逻辑有三层：其一，能力互补——AEVEX的Mako无人水面艇主打ISR与动能作战，BlackSea的GARC（16英尺级、海军第3无人水面艇中队在役试验）则聚焦自主侦察与分布式作战，二者叠加后覆盖"空中-水面-水下"的跨域无人体系；其二，客户接入——对海军与特种作战司令部的渠道价值被明确写进交易说明，收购现成在役装备的研制方，比从零竞标更快进入军种采购链；其三，资本结构——2.5亿现金+3.5亿股票+5000万业绩对价，对价与协同实现挂钩，显示卖方对整合节奏有约束。在美国海军加速无人艇编队（如第3 USVRON）的大背景下，这类收购是中小无人系统公司并入更大国防平台生态的普遍路径。

DISA将JWCC后续合同更名为"JWCC统一云市场"并确立8月24日招标发布日期，标志着国防部云战略进入"超大规模+多元化"并行的新阶段。现有JWCC下AWS以5.265亿美元遥遥领先，微软、Oracle、Google分列其后，任务订单高度集中于头部——这一格局正是本次改革的动因。Tier 2（一切即服务）与Tier 3（商业创新者与小企业）的设计，实质是给中层云服务商、垂直SaaS与新兴厂商打开国防市场入口，同时保留四家超大规模云商作为Tier 1主干。对云生态而言，这是"多供应商、多层级"采购模式的制度化：国防部不再依赖单一云机制，而是构建一个可容纳不同规模厂商的采购漏斗。值得注意的是，DISA对预计合同总额保持沉默，仅明确现有JWCC的90亿美元上限——新合同的体量悬念本身，就是市场博弈的一部分。

太空军向Impulse Space追加两艘Mira航天器，则揭示了TacRS计划的重心迁移：从"快速发射"转向"在轨快速机动"。Victus Salo系列（Salo 1/2/3加Surgo）共四艘，合同总额6280万美元，覆盖LEO承载政府载荷、GTO独立机动等多种场景；Space Safari与DIU的联合授予机制，以及Mira三次成功飞行+氧化亚氮/乙烷化学推进的成熟度，说明太空军正在把"快速响应"从发射环节延伸到轨道运输环节。上个月Impulse获准进入NSSL Phase 3 Lane 1作为上面级供应商，意味着它已从"战术快速响应"的实验角色升级为国家安全发射的正式供应商——太空机动性市场的竞争格局正在形成。

对从业者的观察要点：其一，无人系统并购潮（AEVEX-BlackSea、Leonardo DRS-Raft等）表明，自主平台的"能力聚合+客户接入"并购逻辑仍将延续，拥有在役军种试验项目的小型厂商将成为稀缺标的；其二，JWCC统一云市场8月24日招标文件发布后，Tier 2/Tier 3的入围标准与任务订单结构将直接影响非超大规模云厂商的国防业务机会，值得密切跟踪；其三，TacRS与NSSL Lane 1的双重身份，使Impulse Space成为衡量美国"在轨机动能力"商业化的风向标，其后续发射与任务执行节奏值得关注。

## 结论

本周国防科技新闻呈现"无人化、云化、轨道机动化"三线并进：AEVEX以最高6.5亿美元收购BlackSea补齐海军无人能力，DISA以8月24日为节点推动JWCC向多层开放生态演进，太空军以追加合同把快速响应太空从"快速发射"推向"在轨快速机动"。对观察者而言，无人系统并购整合、国防云市场多元开放与在轨机动商业化的推进速度，将是评估美国国防工业转型的三大指标。
